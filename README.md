## Core research distinction

| Research lens | Focus |
| --- | --- |
| **DAE** | The scope, legitimacy and accountability of agent decisions |
| **ASO** | Whether agents can discover, understand, verify, qualify, select and act |
| **A2A Commerce** | How agents and commercial participants interact within markets |

A2A commerce is used here as an economic interaction concept; it is not synonymous with a single technical protocol. The framework is a proposed analytical system, not an official platform or industry standard.
